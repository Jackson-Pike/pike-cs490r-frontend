# Themes System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add five plug-and-play visual themes (Dark Cinema, Vintage Hollywood, Streaming Service, Retro VHS, Clean Light) selectable from the Profile page, persisted in localStorage, with a View Transitions API ripple animation on switch.

**Architecture:** A `data-theme` attribute on `<html>` drives all visual changes via CSS custom properties defined in a single `themes.css` file. A `ThemeContext` manages state, localStorage persistence, `data-theme` writes, and lazy Google Fonts injection. A `useTheme` hook exposes the context to components. Theme selection UI lives on the existing ProfilePage as a row of five circular swatches.

**Tech Stack:** React 18 (Context + hooks), CSS custom properties, View Transitions API (progressive enhancement), Google Fonts (lazy-loaded via `<link>` swap), localStorage.

## Global Constraints

- `data-theme` must be set on `document.documentElement` (the `<html>` element), not on `#root`
- Dark Cinema is the default theme — it must match the current visual appearance exactly
- Dark Cinema uses system fonts — no Google Fonts `<link>` is injected for it (zero network request on first load)
- All five themes must define exactly the 11 CSS tokens listed in the spec: `--bg`, `--bg-secondary`, `--bg-dark`, `--bg-dark-secondary`, `--text`, `--text-h`, `--primary`, `--border`, `--shadow`, `--sans`, `--heading`
- `var(--green)` must be removed from all component CSS; every occurrence becomes `var(--primary)`
- `--green: #00ff85` must be removed from `index.css` `:root` (it moves into the Dark Cinema theme block in `themes.css`)
- Theme switcher lives on `/profile` — no new route
- View Transitions fallback: if `document.startViewTransition` is undefined (Firefox), the theme switches instantly with no animation
- No new npm packages — everything is vanilla browser APIs + existing React

```jsx
import { createContext, useState, useLayoutEffect } from 'react'

export const ThemeContext = createContext(null)

export const THEMES = [
  { id: 'dark-cinema',       label: 'Dark Cinema',       swatch: '#00ff85', bg: '#121212' },
  { id: 'vintage-hollywood', label: 'Vintage Hollywood', swatch: '#c9a84c', bg: '#f5f0e8' },
  { id: 'streaming-service', label: 'Streaming Service', swatch: '#e50914', bg: '#0a0a0a' },
  { id: 'retro-vhs',         label: 'Retro VHS',         swatch: '#00f5e4', bg: '#0d0015' },
  { id: 'clean-light',       label: 'Clean Light',       swatch: '#6366f1', bg: '#ffffff' },
]

/** Google Fonts href for each theme. Dark Cinema uses system fonts — no link needed. */
const FONT_URLS = {
  'dark-cinema':       null,
  'vintage-hollywood': 'https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;500;700&family=Lora:wght@400;600&display=swap',
  'streaming-service': 'https://fonts.googleapis.com/css2?family=Anton&family=Inter:wght@400;600&display=swap',
  'retro-vhs':         'https://fonts.googleapis.com/css2?family=VT323&family=Share+Tech+Mono&display=swap',
  'clean-light':       'https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;600;700&display=swap',
}

/** Swap the single <link id="theme-fonts"> element, or remove it for system-font themes. */
function injectFonts(themeId) {
  const url = FONT_URLS[themeId]
  let link = document.getElementById('theme-fonts')

  if (!url) {
    // System fonts — remove any existing link
    if (link) link.remove()
    return
  }

  if (!link) {
    link = document.createElement('link')
    link.id = 'theme-fonts'
    link.rel = 'stylesheet'
    document.head.appendChild(link)
  }

  link.href = url
}

export function ThemeProvider({ children }) {
  const [theme, setThemeState] = useState('dark-cinema')

  // useLayoutEffect so the theme is applied before first paint (no flash)
  useLayoutEffect(() => {
    const saved = localStorage.getItem('theme') ?? 'dark-cinema'
    document.documentElement.dataset.theme = saved
    injectFonts(saved)
    setThemeState(saved)
  }, [])

  function setTheme(id) {
    function apply() {
      document.documentElement.dataset.theme = id
      injectFonts(id)
      localStorage.setItem('theme', id)
      setThemeState(id)
    }

    if (document.startViewTransition) {
      document.startViewTransition(apply)
    } else {
      apply()
    }
  }

  return (
    <ThemeContext.Provider value={{ theme, setTheme, themes: THEMES }}>
      {children}
    </ThemeContext.Provider>
  )
}
```
